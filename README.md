# Hi, I'm climashscape 👋

I build tooling around AI coding agents and Linux-first desktop apps — most of my repos start as "scratch my own itch" projects that grow into something reusable.

## What I work on

- **AI agent tooling** — agent skills, MCP servers, spec-driven workflows, and harnesses for working with coding agents
- **Desktop & CLI apps** — Rust / Tauri / TypeScript, Linux-first, offline-friendly
- **Design automation** — generative poster / illustration / zine skills that turn prompts into publishable visuals

## Highlighted projects

| Project | What it does |
| --- | --- |

## This repository: agent-rules

This repo doubles as my GitHub profile. The project it hosts is **agent-rules**: collaboration rules for AI coding agents ([AGENTS.md](AGENTS.md), English version [AGENTS.en.md](AGENTS.en.md)), written for ZCode and tuned to a Linux desktop — see the full [project README](docs/agent-rules.md).
